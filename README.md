# Automated-Web-System-Using-Selenium-WebDriver

## Overview

This project automates the process of logging support requests in a web application using Selenium WebDriver. It seamlessly integrates with a database to fetch issue reports, log them automatically into the web application, and store the generated complaint numbers back into the database.

## Key Features

1. **Automated Login:** Secure login using provided credentials.
2. **Database Integration:** Fetch issues from the database to automate the logging process.
3. **Automated Form Filling:** Automatically fill out various form fields for each issue.
4. **File Upload:** Upload attachments related to each support request.
5. **Complaint Number Extraction:** Retrieve and store the complaint number from the page title after submission.
6. **Database Update:** Update the database with the complaint numbers for each logged issue.
7. **Error Handling:** Manage WebDriver exceptions to ensure smooth execution.
8. **Waiting Mechanisms:** Use explicit waits to handle dynamic page elements and ensure correct sequence of actions.

## Technologies Used

1. **Python:** Scripting and automation.
2. **Selenium WebDriver:** Browser automation.
3. **Chrome WebDriver:** Executes automation in the Chrome browser.
4. **SQLite/MySQL:** Database operations to fetch and store issue data.
5. **ChatGPT:** Provided assistance and guidance during project development.

## Setup and Installation

1. **Install Python:** Download and install the latest version from [python.org](https://www.python.org/).
2. **Install Selenium:** Use the following command to install Selenium:
   ```bash
   pip install selenium
   ```
3. **Download Chrome Driver:** Ensure compatibility with your Chrome browser version. Download from [chromedriver.chromium.org](https://chromedriver.chromium.org/).
